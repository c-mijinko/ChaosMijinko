# ChaosMijinko
生まれ落ちた何か

## かんたんお絵描きSDXL v1.02

Windows向けの、Comfy環境自動設定ツールとSDXL専用お絵描きアプリです。アプリと専用ComfyUI環境は、展開した製品フォルダー内で動作します。

### ダウンロード

[GitHub Releases](https://github.com/c-mijinko/ChaosMijinko/releases) のAssetsから `oekaki_sdxl_v1.02.zip` と `SHA256SUMS.txt` を取得し、ZIPのSHA-256を照合してください。GitHubが自動生成する `Source code (zip)` はソーススナップショットで、本体配布物ではありません。

### 配布物の照合

ファイル：`oekaki_sdxl_v1.02.zip`（5,686,652 bytes）

```text
SHA-256: 7552bbfdfaa9cd86c3fcf0becd22e58f03ad6ccbedfde60fb781874240615785
```

この値は配布物の同一性確認用であり、安全性そのものを保証するものではありません。

### F13での主な改善

- Checkpoint候補は専用ComfyUIの一覧を元に表示します。保存済みの名前が候補から消えた場合は「未確認」として保持し、候補が確認できるまで生成を開始しません。「候補を再取得」で一覧を更新できます。
- 高精細マスク修正の切り出し処理解像度は低負荷768×768、初期値1024×1024、高性能1280×1280から選べます。完成画像の幅・高さは元画像と同じです。
- 基本マスク修正では、マスクの有効値が0の画素を元画像のRGB値で保持し、境界の中間値を合成します。反転設定でも有効マスクを基準にします。

1280設定による画質向上や、試験していないGPU・低VRAM環境での完走を保証するものではありません。

### 必要な環境

- Windows 10/11 x64
- NVIDIA GPU、NVIDIA Driver 580.65.06以上
- インターネット接続、初回設定時に25 GiB以上の空き容量

### 初回の使い方

1. ZIP内の `oekaki_sdxl_v1.02` フォルダー全体を書き込み可能な場所へ展開します。
2. `Comfy環境自動設定ツール.exe` を起動し、画面の利用条件・取得内容を確認してから環境設定を開始します。固定取得量は約4.07 GBです。Managerが取得する追加依存等はこの固定値に含みません。
3. SDXL CheckpointとLoRAは同梱・自動取得されません。各自で用意したファイルをREADME記載の所定フォルダーへ配置します。
4. `かんたんお絵描き.exe` を起動し、ComfyUIを起動してCheckpoint候補を再取得します。

### 実行ファイルと確認方法

同梱の2本のEXEには発行元を証明するコード署名が付いていません。Windowsの保護機能により警告が表示されたり、組織の設定によって実行できなかったりする場合があります。

Comfy環境自動設定ツールは同梱の `setup.ps1` を使い、専用製品フォルダー内に環境を構築します。内部処理で指定する `-ExecutionPolicy Bypass` は起動したWindows PowerShellプロセスとその子プロセスに限られ、システム全体の実行ポリシーを恒久変更しません（[PowerShellの実行ポリシー](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies?view=powershell-7.5)）。Defender等の保護機能も無効にしません。

入手元、取得内容一覧、同梱コード、SHA-256を確認してください。SHA-256の一致は配布物が比較対象と同じ内容かを確認する材料で、安全性の保証やWindows警告の解除ではありません。ZIPとチェックサムを同じ場所から取得した場合、両方が同時に差し替えられていないことまでは確認できません。警告を無条件に無視したり、保護機能を無効にしたりしないでください。

WindowsのSmartScreenは署名やファイルの評価状況を扱い、未署名ファイルや評価情報の少ない新しいファイルでは警告が出ることがあります（[Microsoft SmartScreenの説明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)）。

設定用スクリプトと本体コードは `setup.ps1`、`setup/`、`app/src/` で確認できます。管理対象の実行環境・設定・モデル・出力は専用製品フォルダーを基準にします。今回の設定処理は永続PATHやWindowsサービスを追加しません。追加取得される第三者ソフトウェアの将来の挙動すべてを保証するものではありません。

ComfyUI-Manager経由の固定2ノードは、設定時に公式Registryから受け取ったアーカイブと展開後の全ファイルを、同梱lockのSHA-256・サイズ・ファイル一覧と照合してから後処理へ進みます。本体が管理するComfyUI起動経路でも、同じ2ノードと固定Managerのファイルを照合し、不一致時は起動を止めます。手動でComfyUI本体を直接起動する等、アプリ管理外の起動方法を強制制御するものではありません。
